HyperCard

Many different control sets in the 1990s were built in Apple’s HyperCard for the classic Macintosh. Each station is a stack: a collection of screens called cards. Cards contain buttons and fields and can share a background, which lets a station reuse its navigation and status displays across screens.

The station logic is written in HyperTalk. Scripts attached to buttons, cards, and stacks respond to events such as a mouse click or a card opening. The scripts can also call native extensions (XCMDs). For example, AddColor paints color over the base card graphics. These extensions, along with pictures and sounds, are stored in the original files’ Macintosh resource forks.

The stations were designed to run on separate Macs. HyperCard Program Linking let a script send messages to HyperCard on another station over AppleTalk or request a value from it.

Emulation

Screenshots were captured locally in Basilisk II on an Apple Silicon Mac. The guest used the following configuration:

Emulator
Native ARM64 build of Basilisk II with a Macintosh Quadra 650 ROM.
Guest system
System 7.5.5 on an HFS disk image, with 64 MiB of guest RAM.
Display
1152 × 864 guest display at 256 colors. The HyperCard cards themselves are 800 × 600.
HyperCard
HyperCard 2.4.1 with an 8 MiB preferred memory allocation so its AddColor extension can draw the color overlays.
Graphics and fonts
QuickTime 3.0 for media. The eWorld 1.1 font suitcase supplies eWorld Tight and Espy Sans fonts. The Commador TrueType font was packaged in a classic Mac font suitcase.
