Concepts

Glossary

Controls
The controls are the set of interactive computer software. Controls are a suite of stations which can be networked together. Software controls are just one of the many storytelling tools available to a director. In the control booth, the software sits alongside microphones, soundboards, and video playback.
Core
Core stations are driven by the Flight Director and are not visible to students. They provide visibility into and control over all other stations. Core stations are designed for experienced staff and optimize for information density. It can take time to learn!
Sub-core
Some larger ships have multiple core stations to divide responsibility for monitoring a large number of stations.
Card
A screen. The terminology comes from the HyperCard software, but the concept is retained in later software.
Stations
A collection of cards for a particular role. Typically each computer and student runs a different station.
